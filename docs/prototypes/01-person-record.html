The rebuild below changes no data and adds no component: it uses shadcn defaults and gives the second column something real to hold.

Plate 01 What it costs to build

Reused as-is

Card, CardHeader, CardContent, Tabs, Button, Badge, DropdownMenu — all already in components/ui, all stock.

Deleted

− 5 rail cards · − 1 tab wrapper · − 1 scroll container · − 42 description strings across nine data modules.

New components

None. Nothing here needs a primitive that shadcn does not already ship, and nothing needs a token outside the stock set.

Data layer

Untouched. Same loader, same fields. Only the two contact predicates merge — one boolean, not a schema change.

The mock on the left renders in Nestory’s shipped custom dark palette; the proposal renders in stock shadcn neutral dark, which is the palette the audit recommends restoring.
