Nestory Sheet 02 Archetype List Routes /leases · /properties · /maintenance Redline 2026-08-12

One list archetype, proved on three domains

Finance, Properties and Maintenance render three different tables — but they fail in the same five ways, because each screen builds its own page body instead of inheriting one. Fix the archetype and all three land at once. Turn on gutter guides below to see the actual problem: three different left edges on a single screen, in every case.

Shared failures The same defect, three screens

These are properties of the archetype, not of any one domain. Each is fixed once, in WorkspacePage or ui/table.tsx, and lands on all fourteen list routes.

#FailureLeasesPropertiesCases
S1 Three left gutters on one screen Local nav at 240px, card edge at 220px, toolbar at 232px. The body slot pads nothing, so each layer improvises.
S2 Pagination floats outside the table surface PaginationControls defaults to attached={false}; one call site in the repo overrides it. n/a
S3 Metric strip reports zeros, scoped to “this page” Five of seven lease cells read 0; all six Maintenance chips read 0. Page-scoped totals aren’t actionable. —
S4 Search field plus a redundant submit button The field already submits on Enter. The extra icon button appears on every list screen captured.
S5 A status column with one distinct value Every row reads the same badge. A column where nothing varies carries no information. —

The archetype What all fourteen list routes become

<WorkspacePage>                          ← owns the gutter: px-4 md:px-6. Nothing inside re-pads.
  header    → <PageHeader>                title · one primary action
  localNav  → <LocalWorkspaceNav>         from the same constant as the sidebar children
  body      → toolbar                     search · Filters · live attention chips
            → <Table stickyHeader>        shadcn primitive, inside overflow-x-auto
            → <PaginationControls attached>
</WorkspacePage>

Reused as-is

Table, TableHeader, TableRow, TableHead, TableCell, Button, Badge, DropdownMenu, Tabs — all stock, all already installed.

Deleted

− 7 bespoke tables · − 4 table tokens · − 3 min-height floors · − 3 search submit buttons · − 2 status columns

New components

One. A stickyHeader prop on ui/table.tsx, replacing the same seven-line sticky declaration copy-pasted across seven files.

Data layer

Untouched. Same loaders, same columns, same filters. Only the metric strips change scope — from the current page to the filtered set.
