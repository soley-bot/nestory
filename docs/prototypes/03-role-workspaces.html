NestorySheet 03 Roles Super Admin · Finance Manager · Finance Member Design 2026-08-12

Three roles, one queue-first workspace

Operations already solved this: land the operator in a prioritised queue, give them one primary action, and keep the row light enough to scan. These three workspaces reuse that anatomy rather than inventing a third. Every value below maps to a typed field — nothing here asks a React component to work out permission, ownership, priority, or financial status.

Anatomy Inherited from Operations

PageHeader          title · one primary action
Attention chips     non-zero counts only          ← correction to Operations, which shows six zeros
Queue               the dominant surface, one row per unit of work
Secondary context   below the queue, never competing

A row is a handle, not a record: enough to decide, then click through. Same rule that took the People and Lease rows from three lines to one.
