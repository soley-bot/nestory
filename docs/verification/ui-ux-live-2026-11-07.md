# Verification of the 46 UI/UX fixes

Reviewed 7 November 2026 against the production version from PR #290, commit `bf322a2e4c4023567c7149257dc4321f6178bbd9`. Three domain agents and the coordinator divided shared controls, property/people, finance/reports, and settings/operations. Corrections are on `codex/ui-ux-live-verification-20261107`; they have not been deployed.

## Method and limits

Live checks used the existing authenticated workspace in Chrome, at desktop sizes and 390 × 844 mobile emulation. Local layout checks also covered widths 320, 1024, and 1280. This is browser emulation, not physical-device or screen-reader certification.

After clarification, the user chose synthetic records for cases requiring writes or unavailable data. Live checks therefore used navigation, filters, unsaved drafts, local file selection, and invalid submissions that are rejected before database writes. No valid financial command, customer record, upload, import, invitation, or access change was submitted. Theme synchronization was tested and the original System preference restored. Temporary viewport overrides and all test drafts were cleared.

Every original finding is accounted for below. A live surface check does **not** prove a data-dependent or failure-only trigger. Those distinctions are explicit. Newly discovered failures remain reproducible in production until this follow-up is separately released.

## Corrections from this pass

1. **Tenant handoff:** portfolio summary shortcuts, the Units register, and Property Overview unit links lost the selected tenant. Preserve the tenant through those links, row actions, filter reset/clear, vacancy review, and fallback navigation.
2. **Ledger layout:** six fixed desktop columns overflowed a 430px toolbar. At the live 1280px viewport the toolbar's content extended to 936px, clipping controls even though the outer page did not scroll horizontally. Fit columns to the actual container and give filter-clear buttons readable accessible names.
3. **Maintenance draft recovery:** an action returning validation errors reset the recurrence selector from Weekly to One-time. Explicit action dispatch preserves the draft; a synchronous submit lock and disabled pending fields protect the in-flight request.
4. **Maintenance guidance:** an unselected property displayed “Invalid UUID.” It now asks the user to choose a property, while retaining the same validation and authorization boundaries.
5. **Attention queue context:** View all checks retained the selected property, but its individual property-specific queue links did not. Carry that property into supported Units, Leases, Maintenance, and Ledger filters. Keep workspace-wide People checks global; missing-owner guidance opens the selected property.
6. **Closing confirmation copy:** during the exit animation, a discarded draft briefly changed its message to “Saving is still in progress.” Retain the last open confirmation content until the animation completes.
